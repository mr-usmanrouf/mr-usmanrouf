## 🧭 About

I'm a Data Science student enrolled in the DSMP program, expected to complete in early 2027. My work is centered on Python-based data analysis, statistical modeling, and machine learning — turning raw datasets into structured, interpretable results.

Most project work draws on the standard Python data stack: NumPy and Pandas for data handling, Matplotlib, Seaborn, and Plotly for visualization, and Scikit-learn for classification and regression tasks. Code is organized around readability, reproducible notebooks, and clear documentation rather than one-off scripts.

Based in Pakistan, working across data analysis, applied statistics, and predictive modeling.
